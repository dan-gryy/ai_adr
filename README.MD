# EchoLink — концептуальна ER-модель

## Домен

EchoLink — клієнт-серверний месенджер для обміну повідомленнями між користувачами.

Предметна область охоплює користувачів, чат-кімнати та повідомлення.

## Основні сутності

- **User** — користувач системи.
- **ChatRoom** — чат-кімната, у якій спілкуються користувачі.
- **Message** — повідомлення, створене користувачем у чат-кімнаті.

## Зв'язки

- один `User` може створити багато `Message`;
- одна `ChatRoom` може містити багато `Message`;
- `User` та `ChatRoom` мають зв'язок багато-до-багатьох (M:N).

## Модель даних

ER-модель описана декларативно за допомогою Mermaid ER Diagram.

Для первинних та зовнішніх ключів використовується тип `UUID`.

Фізична схема бази даних, SQL DDL та ORM у цій роботі не моделюються. Зв'язок M:N представлений без фізичної сполучної таблиці, оскільки робота описує концептуальний рівень моделі даних.
