# EchoLink — Термінальний C++ месенджер

## Опис домену
EchoLink — клієнт-серверний консольний месенджер на C++ (POSIX sockets, FTXUI, PostgreSQL) для обміну текстовими повідомленнями в реальному часі в межах тематичних кімнат.
