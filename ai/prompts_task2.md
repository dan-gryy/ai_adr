# Аудит ШІ (Завдання 2 - Use Cases)

## Промпт 1: Генерація Use Cases
> Напиши Use cases та EARS для месенджера EchoLink.

*Аудит помилок:* 
1. ШІ додав "Систему" як ініціюючого актора. Це порушує DoD.
2. Вимоги EARS були сформульовані як `If... then...`. Виправлено власноруч на суворий синтаксис `WHEN <trigger> the system SHALL <reaction>`.
3. У NFR (Нефункціональних вимогах) не було кількісних меж (було просто "система повинна бути швидкою"). Я додав чіткі межі: 200 мс, 500 користувачів, термінал 80x24.
