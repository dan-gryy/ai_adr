# ADR 001: Зв'язок учасників та чат-кімнат в EchoLink

## Контекст
EchoLink є C++ застосунком, що використовує SQLite для зберігання даних. Відповідно, у фізичній реалізації зв'язок учасників із кімнатами вимагає таблиці `User_ChatRoom`. Проте під час побудови концептуальної ER-моделі ШІ також одразу згенерував цю фізичну сполучну таблицю.

## Розглянуті альтернативи
1. Залишити фізичну таблицю (асоціативну сутність), наближаючи модель до SQLite реалізації.
2. Використати прямий концептуальний зв'язок `}o--o{`.

## Рішення
Обрано альтернативу 2 (прямий зв'язок). Оскільки поточна задача — побудова логічної ER-моделі, створення сполучних таблиць порушує рівень абстракції. Факт участі в кімнаті на даному етапі розглядається як чисте відношення без додаткових бізнес-атрибутів (наприклад, статусу модератора), що дозволяє зберегти чистоту концептуальної схеми перед її трансформацією в SQL DDL.
